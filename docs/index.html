When contact_manifold_dim > 0, every point of the returned ContactManifold is drawn (not just one) — a shared line for a 1D contact, a spread of points for a 2D one. The normal is drawn at every point too, since it's the SAME vector everywhere whenever normal_jacobian_valid is true (that's exactly why the API returns one normal, not one per point).
